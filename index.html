``` ### O que verificar no seu Firestore (Console): Se ao clicar em "Diagnosticar ID Antigo" os logs disserem **"Erro ao acessar..."**, a regra de segurança no seu Firebase Console **NÃO** está a permitir a leitura. Certifique-se de que a regra que colocou no Firebase Console é exatamente esta: ```javascript rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /artifacts/tribo-burger-pricing-system/users/{userId}/{document=**} { allow read: if true; // PERMITE LER PARA A MIGRAÇÃO allow write: if request.auth != null && request.auth.uid == userId; } } } ``` Se a regra estiver diferente (ex: `allow read: if request.auth.uid == userId`), o Firebase **bloqueará a migração** porque o seu utilizador atual não tem permissão para ler a pasta do utilizador antigo. **O `allow read: if true` é obrigatório para que a cópia entre IDs funcione.**
